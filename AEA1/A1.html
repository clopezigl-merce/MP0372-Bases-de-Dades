Part C · Teoria: elements d’un SGBD

ElementFunció
DDLCrea, modifica i elimina estructures: CREATE, ALTER, DROP.
DMLConsulta i modifica dades: SELECT, INSERT, UPDATE, DELETE.
DCLPermisos i accessos: GRANT, REVOKE.
Gestió de transaccionsOperacions coherents (ACID).
Sistema d’emmagatzematgeGestiona el disc.
Control de concurrènciaEvita conflictes entre usuaris simultanis.
Control de recuperacióRecupera dades després d’un fallada (TCL: COMMIT, ROLLBACK).
SeguretatProtegeix i restringeix l’accés.

Part D · Fem l’activitat

  1. Elements d’un SGBD: assigna cada operació del document a un element i explica’n la funció.
  2. Sigles: SQL, DML, DDL i DCL: significat i un exemple curt de sentència.
  3. Escenaris: tria el tipus de SGBD per a cada cas (botiga online, xarxa social, streaming, videojocs, banca) i justifica-ho.
  4. Taules: codifica els alumnes de 1r ASIX en una taula, nomena la BD (BD_Nom.bd) i les taules (T_Nom), fes que la 1a columna sigui única (identificador) i afegeix-hi els mòduls matriculats.
  5. Reflexiona: és òptim tenir-ho tot en una taula? Divideix-ho en més taules.

Exemples en SQL (Oracle, esquema HR)

-- DDL
CREATE TABLE t_alumne (
  dni     VARCHAR2(10) PRIMARY KEY,
  nom     VARCHAR2(60),
  edat    NUMBER(3),
  estudis VARCHAR2(30),
  cicle   VARCHAR2(10)
);
-- DML
SELECT employee_id, first_name, last_name, salary FROM hr.employees WHERE department_id = 60;
INSERT INTO hr.departments (department_id, department_name, location_id) VALUES (280, 'Formació', 1700);
UPDATE hr.employees SET salary = salary * 1.05 WHERE job_id = 'IT_PROG';
-- DCL
GRANT SELECT ON hr.employees TO u_david;
REVOKE SELECT ON hr.employees FROM u_david;
-- TCL
COMMIT;  ROLLBACK;
Recorda la diferència: la BD són les dades; el SGBD és el programari que les gestiona.
