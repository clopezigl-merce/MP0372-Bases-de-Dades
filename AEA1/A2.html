ElementDescripció

Registre / campFila / columna d’una taula.

Tipus de BD segons el model

  • Relacionals: taules i SQL (MySQL, Oracle, PostgreSQL).
  • NoSQL: documents o grafs (MongoDB, Cassandra).
  • Orientades a objectes: db4o.
  • Jeràrquiques i en xarxa: arbres i xarxes (IMS).

Segons la ubicació

  • Centralitzada: un únic servidor.
  • Distribuïda: diversos servidors o llocs.
  • Al núvol: servidors remots (AWS, Google Cloud).

Exemples en SQL sobre HR

CREATE VIEW v_empleats_it AS
  SELECT first_name, last_name, salary FROM hr.employees WHERE department_id = 60;
CREATE INDEX idx_emp_hire_date ON hr.employees (hire_date);
SELECT e.last_name, d.department_name
  FROM hr.employees e JOIN hr.departments d ON e.department_id = d.department_id;
