AEA1 · Introducció a les BD

Elements i classificació dels sistemes gestors de bases de dades.

RA1. Reconeix els elements de les bases de dades analitzant-ne les funcions i valorant la utilitat dels sistemes gestors.

Què aprendràs

  • 1.1 Analitza els diferents sistemes lògics d’emmagatzematge i les seves funcions.
  • 1.2 Identifica els diferents tipus de bases de dades segons el model de dades utilitzat.
  • 1.3 Identifica els diferents tipus de bases de dades en funció de la ubicació de la informació.
  • 1.4 Reconeix la utilitat d’un sistema gestor de bases de dades.
  • 1.5 Descriu la funció de cadascun dels elements d’un sistema gestor de bases de dades.
  • 1.6 Classifica els sistemes gestors de bases de dades.
