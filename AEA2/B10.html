Subqueries i UNION, MINUS, INTERSECT.

On posar una subquery

  • WHERE: la més habitual.
  • SELECT: per retornar un valor derivat.
  • FROM: es tracta com una taula.
SELECT last_name, job_id, department_id
FROM employees
WHERE department_id = (SELECT department_id FROM departments WHERE department_name = 'Marketing');

Operadors de conjunts

Funcionen amb camps del mateix tipus.

OperadorEfecte
UNIONUneix sense duplicats (UNION ALL els manté).
MINUSResta el segon resultat al primer.
INTERSECTNomés les files comunes.
SELECT employee_id FROM employees
MINUS
SELECT manager_id FROM employees;
