Variables de substitució

& demana el valor cada vegada; && el desa a la sessió fins a fer UNDEFINE.

SELECT * FROM employees WHERE last_name = '&nom_empleat';
SELECT * FROM employees WHERE last_name = '&&nom_empleat';
UNDEFINE nom_empleat;
Els camps de tipus caràcter van amb cometes simples; els numèrics no.
