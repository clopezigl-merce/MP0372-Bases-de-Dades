B6 · Funcions de conversió

TO_CHAR, TO_DATE, TO_NUMBER, NVL i DECODE.

← AEA2

Funcions

FuncióPer a què serveix
ADD_MONTHSSuma mesos a una data.
TO_CHARConverteix data o número a text amb format.
TO_DATEConverteix text a data.
TO_NUMBERConverteix text a número.
NVLSubstitueix NULL per un valor per defecte.
DECODEUn «IF/CASE» bàsic.
SELECT ADD_MONTHS(SYSDATE, 3) FROM dual;
SELECT TO_CHAR(hire_date, 'DD-MM-YYYY') FROM employees;
SELECT TO_CHAR(hire_date, 'DAY') FROM employees;
SELECT TO_DATE('28-10-2024', 'DD-MM-YYYY') FROM dual;
SELECT last_name, NVL(commission_pct, 0) FROM employees;
SELECT DECODE(job_id, 'IT_PROG', 'Informàtic', 'Altres') FROM employees;
