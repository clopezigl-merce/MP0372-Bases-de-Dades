Producte cartesià

Si seleccionem employees i departments sense relacionar-les, SQL multiplica les files: 107 × 27 = 2.889.

Tipus de JOIN

TipusResultat
JOIN = INNER JOINNomés files amb parella (106 a HR).
LEFT JOINTotes les de l’esquerra, amb NULL si no hi ha parella (107).
RIGHT JOINTotes les de la dreta (122).
FULL OUTER JOINTotes dues bandes (123).
NATURAL JOINDetecta sol el camp comú; deprecated, no l’usem.

Exemples

-- Sense JOIN
SELECT employee_id, last_name, department_id, department_name
FROM employees E, departments D
WHERE E.department_id = D.department_id;

-- USING (més curt)
SELECT employee_id, last_name, department_id, department_name
FROM employees JOIN departments USING (department_id);

-- ON (cal posar àlies)
SELECT E.employee_id, E.last_name, E.department_id, D.department_name
FROM employees E JOIN departments D ON (E.department_id = D.department_id);

-- Només els nuls de les dues bandes (17 files)
SELECT E.employee_id, E.last_name, E.department_id, D.department_name
FROM employees E FULL OUTER JOIN departments D ON (E.department_id = D.department_id)
WHERE E.department_id IS NULL OR D.department_id IS NULL;
